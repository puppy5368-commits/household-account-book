# 우리집 가계부 보드 V1

포함 기능:
- 월 수입 / 실제 지출 / 계좌이동 / 잔액 요약
- 계좌이동은 실제 지출에서 제외
- 민정/남편 필터
- 고정지출 목록
- 카테고리별 실제지출
- 지출/수입/계좌이동 직접 입력
- 영수증·결제화면 사진 첨부
- 브라우저 로컬 저장
- 모바일 반응형

시작 데이터:
- 2026-09-10 월급 5,889,900원
- 십일조 600,000원
- 개인회생 2,044,000원
- 민정 7777 계좌이동 2,700,000원
- 남편 고정비 통장 계좌이동 300,000원
- 쿠팡 누룽지팝 4개 9,100원
- 현재까지 알려준 민정/남편 고정비 전체

실행: index.html을 브라우저에서 열면 됩니다.

- 고정비 자동 반복
